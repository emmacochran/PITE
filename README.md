# PITE: Physics-informed transpiration estimates

A neural network built in PyTorch to partition transpiration from eddy covariance data.

For a tutorial on how to use PITE, see application.ipynb
  - the example is run using data from AmeriFlux site: US-MOz (https://ameriflux.lbl.gov/sites/siteinfo/US-MOz)
  - years include 2012-2014 where 2012 was a severe drought year at the site

Requirements:
- tested on Python 3.14
- if using a CPU or a Mac (either CPU or GPU), see requirements.txt for packages
- if using Windows and a GPU, see requirements_windows_GPU.txt for packages

This is a work in progress and will be continuously updated

This is a companion repository to an in-progress manuscript.
